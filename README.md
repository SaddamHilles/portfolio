# Saddam Hilles — Portfolio

Personal site for a senior frontend engineer. Built with Next.js, TypeScript, and Tailwind CSS.

```bash
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — selected work, experience, capabilities
- `/work` — case study index
- `/work/[slug]` — long-form case studies
- `/about`
- `/contact`

Update contact, social links, and live URLs in `src/data/site.ts`.
